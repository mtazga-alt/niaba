# ميزان — منظومة متابعة النيابات (PWA)

تطبيق ويب قابل للتثبيت على الكمبيوتر والموبايل. البيانات محفوظة في مستودع GitHub خاص، والمزامنة تتم بين جميع المستخدمين، ويعمل التطبيق دون إنترنت ثم يرفع التغييرات عند عودة الاتصال.

## محتويات المجلد
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً |
| `sw.js` | تشغيل التطبيق دون اتصال |
| `manifest.webmanifest` | بيانات التثبيت كتطبيق |
| `icons/` | أيقونات التطبيق |

## خطوات النشر (مرة واحدة)

### 1) مستودع التطبيق (عام)
1. أنشئ مستودعاً جديداً على GitHub، مثلاً `mizan`.
2. ارفع كل الملفات الموجودة في هذا المجلد كما هي (مع مجلد `icons`).
3. من **Settings ← Pages**: اختر Source = `Deploy from a branch`، والفرع = `main`، والمجلد = `/ (root)`، ثم احفظ.
4. بعد دقيقة سيكون رابط التطبيق: `https://اسم-حسابك.github.io/mizan/`

### 2) مستودع البيانات (خاص)
1. أنشئ مستودعاً **Private** باسم مثل `mizan-data`، وفعّل خيار **Add a README file** عند الإنشاء.
2. لا ترفع فيه شيئاً، فالتطبيق سينشئ مجلد `data/` تلقائياً.

### 3) رمز الوصول (Token)
1. من **Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token**.
2. اختر **Only select repositories** ثم حدد `mizan-data` فقط.
3. من **Repository permissions** اجعل **Contents = Read and write**.
4. اختر مدة صلاحية مناسبة (مثلاً سنة)، ثم انسخ الرمز الذي يبدأ بـ `github_pat_`.

> ⚠️ لا تضع الرمز داخل أي ملف في مستودع التطبيق، لأن GitHub يلغي الرموز المنشورة علناً تلقائياً. يُدخَل الرمز من داخل التطبيق فقط.

### 4) أول تشغيل (المسؤول)
1. افتح رابط التطبيق ثم اختر تبويب **إعداد كمسؤول**.
2. أدخل اسم حسابك على GitHub، واسم مستودع البيانات، والرمز، ثم اضغط **اختبار الاتصال**.
3. أنشئ حساب المسؤول (الاسم، واسم الدخول، وكلمة المرور).
4. من **الإدارة ← النيابات** أضف النيابات.
5. من **الإدارة ← المستخدمون** أنشئ الحسابات (الاسم، واسم الدخول، وكلمة المرور، والنيابة التابع لها).
6. من **الإدارة ← الربط والمشاركة** انسخ **رابط الربط** وأرسله للمستخدمين بشكل خاص.

### 5) المستخدمون
- يفتح المستخدم رابط الربط مرة واحدة على جهازه، ثم يسجل الدخول باسم المستخدم وكلمة المرور.
- للتثبيت كتطبيق: من قائمة المتصفح اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

## كيف تعمل المزامنة والإشعارات
- كل إضافة أو تعديل يُحفظ فوراً على الجهاز، ثم يُرفع إلى GitHub خلال ثوانٍ.
- التطبيق المفتوح يفحص التغييرات كل 10 ثوانٍ. الفحص الذي لا يجد جديداً لا يُحتسب من حد طلبات GitHub.
- عند وصول تحديث من مستخدم آخر يظهر تنبيه داخل التطبيق وإشعار على الجهاز بعد تفعيل الإشعارات. المسؤول يستقبل كل التحديثات، والمستخدم يستقبل ما يخص نيابته.
- إذا عدّل مستخدمان في الوقت نفسه، يدمج التطبيق التعديلات تلقائياً ولا يضيع أي منها.
- **دون اتصال:** يستمر العمل وتُحفظ التغييرات على الجهاز، ويظهر عددها بجوار مؤشر الاتصال، ثم تُرفع تلقائياً عند عودة الإنترنت.
- **حد معروف:** الإشعار يصل ما دام التطبيق مفتوحاً، حتى لو كان في الخلفية. أما إذا أُغلق التطبيق تماماً فيحتاج ذلك إلى خادم إشعارات (Push)، وهو غير متاح مع GitHub وحده.

## ملاحظات أمنية
- يجب أن يبقى مستودع البيانات **خاصاً**.
- رابط الربط يحتوي على الرمز، فأرسله للمستخدمين في رسائل خاصة فقط.
- كلمات المرور تُحفظ مشفّرة بـ SHA-256، وليست مكتوبة نصاً.
- لإلغاء وصول الجميع: احذف الرمز من GitHub وأنشئ رمزاً جديداً، ثم حدّثه من **الإدارة ← الربط والمشاركة**، وأرسل رابط الربط الجديد.

## تحديث التطبيق لاحقاً
ارفع ملف `index.html` الجديد، ثم غيّر رقم `VERSION` في أعلى ملف `sw.js`، مثلاً إلى `mizan-v1.0.1`. سيظهر للمستخدمين زر «يتوفر تحديث جديد».
